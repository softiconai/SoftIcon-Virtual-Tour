A 360° panorama and virtual tour block. Add scenes and hotspots right in the block editor. No external services.

== Description ==

**SoftIcon Virtual Tour** adds a **Virtual Tour** block to the block editor. Choose your 360° panorama images from the Media Library; each one becomes a scene of the tour.

* **Build it in the block editor** – no separate admin page, no shortcode.
* **Up to 50 scenes per tour** – and up to 50 hotspots in each scene.
* **Full image quality** – the block uses your original upload, not the smaller copy WordPress makes of big images.
* **Works without JavaScript** – the first scene is a real image with its alt text, so search engines and every visitor can see it.
* **No external services** – every file is on your site. No API key, no CDN, no cookies, no tracking.

= Privacy =

The plugin sets no cookies, stores nothing about visitors and connects to no outside service. Your scenes are saved in the block, inside your post.

== Installation ==

1. Install the plugin from **Plugins → Add New**, or upload the zip, and activate it.
2. In the block editor, add the **Virtual Tour** block.
3. Choose or upload your 360° panorama images.

== Frequently Asked Questions ==

= What images can I use? =

Equirectangular 360° panoramas: the image is twice as wide as it is high (2:1), for example 6000 × 3000 pixels. Most 360° cameras and phone panorama apps save this format.
