# SoftIcon Virtual Tour

A WordPress block for 360° panoramas and virtual tours. Add scenes and hotspots right in the block editor. No external services.

## Development

```bash
npm install
npm run start   # watch
npm run build   # production build
npm run lint
npm run zip     # build + translations + release zip
```

Shared editor helpers come from the `softicon-tools` folder next to this plugin. `npm run tools` copies them into `src/vendor/softicon-tools/` before each build.
